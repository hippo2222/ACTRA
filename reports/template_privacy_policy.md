# Шаблон: Политика приватности

> Черновой шаблон. Перед публикацией требуется юридическая проверка.

## 1. Общие положения
- Настоящая Политика описывает, какие данные обрабатывает **[НАЗВАНИЕ ПРОДУКТА]** и для каких целей.
- Оператор персональных данных: **[ЮР. ЛИЦО / ИП]**, **[РЕКВИЗИТЫ]**.
- Контакт по вопросам приватности: **[PRIVACY EMAIL]**.

## 2. Какие данные мы обрабатываем
- Данные профиля: имя профиля, настройки, технические идентификаторы профиля.
- Технические данные устройства (по необходимости и/или с согласия): версия приложения, ОС, язык интерфейса, диагностические события.
- Данные обратной связи: тема, текст сообщения, вложенные технические сведения (если пользователь разрешил).

## 3. Цели обработки
- Предоставление и поддержка функционала приложения.
- Обработка обращений пользователей и исправление ошибок.
- Обеспечение безопасности и предотвращение злоупотреблений.
- Улучшение качества продукта на основе агрегированной аналитики.

## 4. Правовые основания
- Исполнение пользовательского соглашения.
- Согласие пользователя (где применимо, например для расширенной диагностики).
- Законные интересы оператора в части защиты сервиса и улучшения качества.

## 5. Хранение данных
- Данные хранятся в течение срока, необходимого для целей обработки, либо до отзыва согласия/удаления профиля, если применимо.
- Сроки хранения для отдельных категорий данных:
  - feedback: **[СРОК]**
  - журналы диагностики: **[СРОК]**
  - данные аккаунта: пока профиль активен.

## 6. Передача третьим лицам
- Данные могут передаваться подрядчикам (хостинг, аналитика, support) только в необходимом объеме и по договорным гарантиям конфиденциальности.
- Продажа персональных данных не осуществляется.

## 7. Международная передача (если применимо)
- При трансграничной передаче обеспечиваются предусмотренные законом механизмы защиты данных.

## 8. Права пользователя
- Право на доступ к данным.
- Право на исправление/обновление данных.
- Право на удаление данных (в пределах, допускаемых законом).
- Право на отзыв согласия на необязательные виды обработки.
- Право на обращение в уполномоченный орган по защите данных.

## 9. Безопасность
- Применяются организационные и технические меры защиты данных:
  - разграничение доступа;
  - журналирование действий;
  - шифрование данных при передаче (TLS);
  - регулярные обновления и патчи безопасности.

## 10. Дети
- Приложение не предназначено для лиц младше **[ВОЗРАСТ]** без согласия законных представителей (если применимо законодательством).

## 11. Изменения Политики
- Политика может обновляться. Актуальная версия публикуется в приложении.
- При существенных изменениях пользователь уведомляется и, при необходимости, повторно подтверждает согласие.

## Чеклист для тестирования на реальных пользователях

### Подготовка к тестированию
- [ ] Подготовить тестовое задание с изображением
- [ ] Подготовить список задач для пользователей
- [ ] Записать сессию тестирования (с разрешения пользователя)

### Сценарии для тестирования

#### Сценарий 1: Создание простой аннотации
1. [ ] Пользователь может найти кнопку режима рисования
2. [ ] Пользователь может выбрать инструмент "Точка"
3. [ ] Пользователь может кликнуть на изображение для создания точки
4. [ ] Точка появляется на изображении
5. [ ] Точка появляется в списке аннотаций

#### Сценарий 2: Создание полигона
1. [ ] Пользователь может выбрать инструмент "Лассо"
2. [ ] Пользователь может кликнуть для добавления точек полигона
3. [ ] Полигон отображается во время рисования
4. [ ] Пользователь может завершить полигон (двойной клик или правый клик)
5. [ ] Полигон сохраняется и появляется в списке

#### Сценарий 3: Создание freehand линии
1. [ ] Пользователь может выбрать инструмент "Карандаш"
2. [ ] Пользователь может рисовать линию, удерживая кнопку мыши
3. [ ] Линия отображается во время рисования
4. [ ] Линия упрощается после завершения
5. [ ] Линия сохраняется и появляется в списке

#### Сценарий 4: Выбор и редактирование
1. [ ] Пользователь может переключиться в режим "Выбор"
2. [ ] Пользователь может кликнуть на аннотацию для выбора
3. [ ] Выбранная аннотация визуально выделяется
4. [ ] Пользователь может переключиться в режим "Редактирование"
5. [ ] Пользователь может перетащить точку аннотации
6. [ ] Изменения сохраняются

#### Сценарий 5: Удаление и отмена
1. [ ] Пользователь может удалить выбранную аннотацию
2. [ ] Пользователь может отменить удаление (Ctrl+Z)
3. [ ] Пользователь может повторить действие (Ctrl+Y)
4. [ ] Пользователь может очистить все аннотации

## Чеклист: Удобство переключения режимов

### Визуальные индикаторы
- [ ] Текущий режим четко виден (выделен/активен)
- [ ] Иконки режимов понятны без подсказок
- [ ] Текст кнопок режимов читаем (если есть)
- [ ] Цветовая схема помогает различать режимы

### Переключение через UI
- [ ] Переключение режима происходит мгновенно
- [ ] При переключении режима отменяются незавершенные операции
- [ ] Выбор инструмента автоматически переключает в режим draw
- [ ] Нет конфликтов между режимами

### Переключение через горячие клавиши
- [ ] Клавиша `V` переключает в режим select
- [ ] Клавиша `E` переключает в режим edit
- [ ] Клавиша `D` переключает в режим draw
- [ ] Горячие клавиши работают когда canvas в фокусе
- [ ] Горячие клавиши не конфликтуют с другими функциями

### Обратная связь
- [ ] Курсор меняется в зависимости от режима
- [ ] Статус-бар показывает текущий режим (если есть)
- [ ] Визуальные подсказки помогают понять текущий режим

### Проблемы, на которые обратить внимание
- [ ] Пользователь забывает переключить режим
- [ ] Пользователь не понимает, какой режим активен
- [ ] Переключение режима происходит случайно
- [ ] Горячие клавиши не работают в некоторых ситуациях

## Рекомендации по улучшению UX (на основе анализа кода)

### 1. Добавить tooltips для кнопок
**Текущее состояние**: Иконки без текстовых подсказок могут быть непонятны
**Рекомендация**: Добавить tooltips при наведении:
- "📝 Режим рисования (D)"
- "👆 Режим выбора (V)"
- "✏️ Режим редактирования (E)"

### 2. Добавить статус-бар
**Текущее состояние**: В коде есть `_update_mode_status()`, но нужно проверить реализацию
**Рекомендация**: Показывать текущий режим и инструмент в статус-баре

### 3. Улучшить визуальную обратную связь
**Текущее состояние**: Реализована цветовая схема для аннотаций
**Рекомендация**: 
- Добавить визуальное выделение активного режима в toolbar
- Показывать курсор в зависимости от режима (реализовано в `_update_cursor()`)

### 4. Добавить справку по горячим клавишам
**Текущее состояние**: Горячие клавиши реализованы, но нет справки
**Рекомендация**: Добавить меню "Помощь" → "Горячие клавиши" или диалог с подсказками

### 5. Улучшить сообщения об ошибках
**Текущее состояние**: Есть базовые предупреждения
**Рекомендация**: Добавить более информативные сообщения:
- "Выберите аннотацию перед удалением"
- "Завершите полигон перед переключением режима"

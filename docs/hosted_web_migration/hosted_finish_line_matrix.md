# Hosted Finish Line Matrix

Дата обновления: `2026-06-25`

Этот документ — каноническая readiness-матрица для финального hosted-перехода уровня `Product + Launch`.
Он больше не описывает только `complex passage` и не допускает расплывчатое состояние вида "вроде работает".

Допустимые статусы только три:

- `green` — hosted source of truth зафиксирован, silent fallback на критическом пути не считается нормой, есть официальный gate или понятный smoke для релиза.
- `transitional` — целевая hosted-модель уже видна в коде, но рядом все еще живут compatibility/fallback codepath'ы, file-backed state или незакрытый launch/gate слой.
- `blocked` — для surface еще нет decision-complete hosted finish-line: либо source of truth не доведен, либо живой продуктовый scope/gate не закреплен, либо текущая реализация остается legacy-first.

## Решения, которые больше нельзя оставлять неявными

1. `main/quick access` теперь использует `user.settings["web_ui_state"]` как hosted truth и зафиксирован отдельным gate `npm run smoke:main-quick-access:hosted`; `ui_state.json` остается только legacy-local compatibility path.
2. `statistics + progress` теперь используют hosted repositories как source of truth и зафиксированы отдельным gate `npm run smoke:statistics:hosted`; file-backed progress/statistics state больше не держит этот contour в `transitional`.
3. `calendar + schedule + memory health` теперь используют `HostedCalendarRepository` как hosted truth и зафиксированы отдельным gate `npm run smoke:calendar:hosted`; blocked hosted reads больше не прячутся в generic `500`.
4. `assets/media` теперь считаются `green`: hosted current-task/runtime contour и core editors используют asset-first contract, а отдельный gate `npm run smoke:assets-media:hosted` закрепляет backend/runtime/editor proof одной командой.
5. `task editor CRUD` теперь считается `green`: hosted catalog/load/bootstrap/save/delete proof закреплен отдельным gate `npm run smoke:task-editor:hosted`, включая degraded behavior и ownership semantics.
6. `complex editor CRUD` теперь считается `green`: hosted complex state больше не bootstrap'ится из `complexes.json`, autosave/history/restore используют hosted persistence, а gate `npm run smoke:complex-editor:hosted` закрепляет CRUD/open/publish/degraded proof одной командой.
7. `theory editor + theory center` теперь считаются `green`: hosted theory metadata/content/history живут на repository-backed truth, blocked hosted reads/writes отдают canonical degraded payload, а gate `npm run smoke:theory-editor:hosted` закрепляет CRUD/history/restore/theory-center proof одной командой.
8. `catalog + library + publication` теперь считаются `green`: hosted catalog больше не bootstrap'ится из `catalog.json` и не зеркалит успешные hosted mutations обратно в shadow state, а gate `npm run smoke:catalog-library:hosted` закрепляет `publish -> list -> add -> open -> visibility/access-code -> degraded` одной командой.
9. `AI editor extras` now use one explicit placeholder contract: public AI routes and AI-driven microcards generation return `ai_mode_in_progress`, while the editor modal renders one honest `Функционал в разработке` state instead of partially-live behavior.
10. `import/export` теперь считается обязательной частью finish-line, значит его нельзя оставлять в статусе "legacy utility, разберёмся потом".
11. `/api/ready` уже полезен как infra telemetry, но еще не заменяет cross-product finish-line matrix.

## Следующий этап после этой матрицы

Следующий рабочий этап должен идти не "по ощущениям", а по строкам выше:

1. Идти по `readiness` и `hosted infra + launch`.

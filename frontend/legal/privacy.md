# Политика приватности

Версия: 2026-02-15.1  
Дата вступления в силу: 2026-02-15

## 1. Какие данные обрабатываются
- Данные профиля (имя, настройки, параметры безопасности).
- Учебный прогресс и статистика.
- Данные обратной связи (если пользователь отправляет сообщение).

## 2. Для чего используются данные
- Для работы функционала приложения.
- Для сохранения прогресса и персонализации.
- Для исправления ошибок и улучшения продукта.

## 3. Технические данные
Техническая информация прикладывается к обратной связи только при явном согласии пользователя.

## 4. Хранение
Данные хранятся локально и/или на инфраструктуре разработчика в объеме, необходимом для работы сервиса.

## 5. Права пользователя
Пользователь может запросить удаление или изменение своих данных в рамках доступного функционала и применимого законодательства.

## 6. Изменения политики
При изменении версии политики пользователь может быть запрошен на повторное согласие.

## 7. Контакты
По вопросам обработки данных: privacy@actra.local
